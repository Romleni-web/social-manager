# Deployment Guide

This guide will help you deploy the Social Media SaaS Platform to **Render** (Backend) and **Vercel** (Frontend).

## 1. Backend Deployment (Render)

1.  **Create a New Blueprint**:
    - Log in to [Render](https://render.com).
    - Click **New +** -> **Blueprint**.
    - Connect your GitHub repository.
    - Render will automatically detect the `render.yaml` file and set up:
        - PostgreSQL Database
        - Redis Instance
        - Node.js Web Service (Express)
    - **Note**: Ensure you use a paid plan (Starter/Standard) for the Database and Redis if you need persistence and high availability.

2.  **Post-Deployment**:
    - Once the backend is deployed, copy the **Service URL** (e.g., `https://social-media-backend.onrender.com`).
    - Go to the `social-media-backend` service settings in Render and update the `FRONTEND_URL` environment variable to your Vercel URL once you have it.

## 2. Frontend Deployment (Vercel)

1.  **Create a New Project**:
    - Log in to [Vercel](https://vercel.com).
    - Click **Add New** -> **Project**.
    - Import your GitHub repository.
2.  **Configure Project**:
    - Vercel will detect the `frontend/` folder due to the `vercel.json` configuration.
    - In the **Environment Variables** section, add:
        - `NEXT_PUBLIC_API_URL`: `https://social-media-backend.onrender.com/api` (Use your actual Render URL).
3.  **Deploy**:
    - Click **Deploy**.

## 3. Database Initialization

After the backend is deployed on Render, you need to push the Prisma schema to the production database:

1.  Open the Render Dashboard.
2.  Go to the **Shell** tab of your `social-media-backend` service.
3.  Run the following command:
    ```bash
    npx prisma db push
    ```

## 4. Environment Variables Checklist

### Backend (Render)
- `DATABASE_URL` (Auto-filled by Blueprint)
- `REDIS_URL` (Auto-filled by Blueprint)
- `JWT_SECRET` (Auto-generated by Blueprint)
- `FRONTEND_URL` (Your Vercel URL)
- `OPENAI_API_KEY` (Add manually)
- `GOOGLE_CLIENT_ID` / `SECRET` (Add manually)

### Frontend (Vercel)
- `NEXT_PUBLIC_API_URL` (Your Render API URL)
